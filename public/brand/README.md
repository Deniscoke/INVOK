The footer shows the EU emblem (generated as SVG — always correct) plus partner
wordmarks. To upgrade the wordmarks to the **official logos**, drop these files
here and tell me to switch them on — I'll swap the text for `<img>` with no layout
change:

| File | Logo | Notes |
|------|------|-------|
| `psc.png` (or `.svg`) | PSC n.o. | transparent background preferred |
| `program-slovensko.png` | Program Slovensko | the official 2021–2027 mark |
| `ministerstvo-prace.png` | Ministerstvo práce, sociálnych vecí a rodiny SR | state emblem version |

Guidelines (Program Slovensko publicity rules):
- The **EU emblem must be at least as large** as the largest other logo.
- "Spolufinancované Európskou úniou" must appear next to the EU emblem (it does).
- Don't modify or recolor the EU emblem.

Recommended height ~34–40 px, exported at 2× for sharpness.
